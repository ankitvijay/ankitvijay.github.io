[sg_popup id=”3″ event=”onload”][/sg_popup]Recently, I came across an interesting tool named [**Remark**](https://github.com/gnab/remark) (all thanks to my colleague)**.**Remark helps to transform your markdown into a slideshow on a browser. It is very simple and easy to use.

To create a presentation with remark all you need to know is a markdown syntax and a little bit  HTML/ CSS. It can be a great alternative to Microsoft PowerPoint. Remark has support for adding speaker notes to the slide, presentation mode, customized slide, syntax highlighting. etc. You can create your presentations through a simple text (HTML) file an efficient manner. It can save you lot of time and help you focus on the content of your slides rather than understanding the tool itself.

You can find a sample of slideshow with remark [here](https://remarkjs.com/).

Documentation is available [here](https://github.com/gnab/remark/wiki).

So, try using remark for your next presentation and see if it helps 🙂
